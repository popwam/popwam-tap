# Material icon subset

Only extended vectors referenced by Android source are vendored from AndroidX Material Icons 1.7.8 (Apache-2.0); each source retains its copyright/license header. Core vectors continue to use material-icons-core. This avoids shipping the entire unused extended catalog in unminified builds. Existing imports and artwork are unchanged.
